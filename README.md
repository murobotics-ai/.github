# Mu Robotics organization configuration

This repository provides shared community-health defaults for repositories in the organization.

- [`CONTRIBUTING.md`](CONTRIBUTING.md) — organization-wide contribution guidance.
- [`SUPPORT.md`](SUPPORT.md) and [`SECURITY.md`](SECURITY.md) — support and vulnerability-reporting paths.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) and [`.github/pull_request_template.md`](.github/pull_request_template.md) — default collaboration templates.

Project-specific files take precedence when an individual repository needs a different workflow.
