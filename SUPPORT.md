# Mu Robotics support

## Dataset pilots

If your team needs task-specific manipulation data, visit [murobotics.ai](https://murobotics.ai/) to plan a focused pilot. Include the target task, robot or gripper, environment, approximate demonstration count, required signals, and preferred delivery format when possible.

## Open-source projects

For setup help, unexpected behavior, or a feature request, use the issue tracker in the relevant repository:

- [HandUMI hardware](https://github.com/murobotics-ai/handumi-hw/issues)
- [HandUMI Quest app](https://github.com/murobotics-ai/handumi-quest-app/issues)

The main HandUMI capture software is still being prepared for public release. Until then, use the HandUMI hardware issue tracker for interface-wide questions.

Before opening an issue, search existing issues and read the repository's setup and troubleshooting documentation. Include only information that is safe to share publicly.

Security vulnerabilities should follow [our security policy](SECURITY.md), not a public issue.
